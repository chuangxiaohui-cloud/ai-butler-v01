Bocha 博查

  • 角色：中文语料 + publish_time 全覆盖；人工综合垫底(1.90)、0 分集中，但有 6 个独家赢局
  • 配额：日配额 [P-63]
  • 实测：P50 ≈ 235ms，最快
  • 超时：跟随总限时 ≤[P-02]
常开可靠源

AnySearch

  • 角色：0 分最少、最稳；通吃通用 + 严肃，综合 2.23
  • 配额：日配额 [P-65]
  • 实测：P50 ≈ 1.15s，P95 ≈ 4.2s
  • 超时：跟随总限时 ≤[P-02]
条件并联 · 质量增强

Tavily

  • 触发：实时 / 英文 / 低置信提示
  • 配额：月配额 [P-64]，超时 ≤[P-35]=3s
  • 实测：综合最高 2.25，P50 ≈ 239ms，P95 ≈ 2.4s
  • AI Answer：100% 覆盖，统一进 Stage 4 过滤
  • 禁区：医疗/政务严肃通道不触发
三路心跳 [P-37]
Bocha / AnySearch / Tavily 持续健康探测；任一路掉线，另外两路无缝顶上，结果不阻塞管道。
统一过滤原则
所有引擎结果（含 Tavily AI Answer）统一进 Stage 4 过滤与打分；Stage 4 评定为高置信后才传给 Stage 5 优先采纳。
规则③ 安全阀
Stage 3 入口串行拦截器：命中 → 严肃通道（双引擎从严并联），Tavily 熔断；未命中 → 三引擎条件并联。
配额熔断
任一路日/月配额耗尽 = 当日熔断，等同心跳掉线；其余引擎撑住，不报错。日请求量级按几十级假设，流量增长时先复算配额。
常开 每次请求都执行 条件触发 满足触发条件才并联（虚线 = Tavily） 禁区 严肃通道禁止 兜底 单路超时/掉线自动切换 契约：answer(query) → { answer, confidence, evidence[], gate_triggered }；gate 来源：规则③→safety / 门控→low_confidence / Stage2→emergency
