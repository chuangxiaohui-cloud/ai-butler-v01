# 推进计划：显式记忆纠正指令

> 日期：2026-09-12 · 分支：v0.2b · 状态：已完成

## 目标

落实 §8.3.2“用户纠正永远优先”：提供严格、可审计的自然语言入口，将旧事实原位替换为用户明确给出的新事实。

## 计划

1. 为纠正指令语法、普通问句防误触与 pipeline 短路行为补测试。
2. 在共享 pipeline 路由前调用既有 `correctMemoryFact()`，按新内容重新计算人格事实层级。
3. 同步 E370、目录文档与交接，完成低成本验证。

**验收标准**

- `纠正记忆：旧内容 → 新内容` 和 `更正记忆：旧内容改为新内容` 可解析；缺失任一侧不命中。
- 命中后旧事实消失、新事实以 corrected 来源保存并重算 kind/layer，且不触发搜索。
- 无记忆存储时诚实提示未保存，不虚报成功。
- 主项目构建与定向测试通过；不运行 E2E/bench，不提交。

## 执行过程

### 改动

- `memory-instruction.ts` 新增严格记忆纠正解析，支持箭头与“改为”分隔。
- `PipelineDeps.userContextStore` 补 `correctMemoryFact` 契约；pipeline 在搜索/路由前执行纠正短路并记录回复轨迹。
- 新事实沿用 E369 分类，纠正来源为 corrected；失败时返回未保存提示。

### 遇到的问题

- 普通“你说错了”无法可靠确定要替换的旧事实与新事实，因此不做猜测，仅接受双端内容完整的严格语法。
