# 推进计划：已解决生活话题退出活跃上下文

> 日期：2026-09-12 · 分支：v0.2b · 状态：已完成

## 目标

落实 §8.3.1：生活栏中已明确解决的日常/情绪话题退出活跃会话窗口，并以 L2 人格学习素材保留。

## 计划

1. 新增严格的解决信号与日常/情绪话题识别
2. 原子移出最近一组相关问答，保留其他会话内容
3. pipeline 将移出的主题写入生活栏 L2 人格事实
4. 更新项目文档与当日交接

**验收标准**

- 只有生活栏且存在明确解决信号时触发
- 最近相关问答退出活跃上下文，技术/普通上下文不误删
- 被移出主题以 L2 事实保留，后续可在记忆管理中追溯
- 主项目构建与定向单测通过

## 执行过程

### 改动

- `SessionContextStore.resolveLatestLifeTopic()` 以文件锁内原子读改写移出最近相关问答。
- 结束信号仅接受“解决了/没事了/好多了/想通了”等明确表达；话题仅识别保守的日常/情绪词。
- pipeline 只在生活栏调用，移出内容以 inferred、life scope 的 L2 事实写入 UserContextStore。
- 已解决生活/情绪素材在 persona 分类中固定为 general/L2，不影响其他事实分类。

### 遇到的问题

- 初次规则漏识别“我好多了”的主语前缀；补齐“我/问题/事情/这事”后通过，未放宽为单独“谢谢”等模糊信号。
