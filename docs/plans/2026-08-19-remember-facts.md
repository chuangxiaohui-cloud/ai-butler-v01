# 推进计划：B 套记忆与回溯修复（E133/E134）

> 日期：2026-08-19 · 分支：v0.2b · 状态：已完成

## 目标

修 P04/P07 的种子轮问题：用户说“记住：...”时，Agent 应直接写入
`user_facts`（`user_explicit`）并简短确认，不再触发外部搜索或输出资料质疑；
后续“老规矩/老样子”通过记忆注入召回该事实。同时补 C03 回溯边界：
问“刚才说的 X”时只能引用历史记忆，记忆里没有就明说，不把通用经验说成刚才说过。

## 计划

1. 新增 `src/agent/memory-instruction.ts`，解析 `记住：...` 指令。
2. `pipeline` 在路由前拦截记住指令，写入 `UserContextStore.addFact` 并返回确认。
3. `PipelineDeps.userContextStore` 类型补 `addFact`。
4. Stage 5 增加“刚才/上次”回溯边界提示。
5. 补单测：记住写入、后续召回、非记住指令不受影响、回溯边界注入。
6. 登记 E133/E134，更新计划结果与当天交接。

**验收标准**

- `记住：导出嘉立创时，Gerber 要关闭钻孔文件...` 返回“已记住”，evidence 为空。
- 同 userId 下一轮 `老规矩，把这个原理图导出给嘉立创。` 的记忆注入包含该事实。
- 非 `记住：` 开头的普通问题不提前短路。
- `刚才说的 X` 提问的系统提示含“只能引用历史记忆，没有就明说”。
- 主项目 build、单测全绿、doc-lint 通过。
