# 推进计划：PPT 主题定制（E141）

> 日期：2026-08-19 · 分支：v0.2b · 状态：已完成

## 目标

`office-daily` 生成项目汇报 PPT 时支持主题色定制，例如
“蓝色主题”“红色主题”，输出 PPT 的标题与正文使用对应强调色。

## 计划

1. `office_pptx_create.py` 支持 `accent` 十六进制色。
2. `office-daily` 从 query 解析中文/英文主题色，写入 PPT spec。
3. 补单测与交接记录。

**验收标准**

- `帮我做一份蓝色主题的项目汇报PPT` 生成的 `.pptx` 使用蓝色强调色。
- 无主题色时沿用默认。
- 主项目 build、单测全绿、doc-lint 通过。

## 执行过程

### 改动

- `scripts/office_pptx_create.py`、`src/skills/office-daily/index.ts`、测试。

### 遇到的问题

- LLM 返回 PPT spec 时不能覆盖已解析的主题色；合并时保留 `accent`。

## 结果

- CLI 真跑“蓝色主题”生成 PPT，读取标题颜色为 `4472C4`。
- `npm run test:all` 单测 423/423 + 集成 17/17 全绿；`doc-lint` 通过。
