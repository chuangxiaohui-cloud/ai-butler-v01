# 推进计划：v1.0 S3 MCP 子 Agent（注册表 + 调度器 + 安全白名单）

> 日期：2026-08-23 · 分支：v0.2b · 状态：进行中

## 目标

v1.0 切片第三片（S3）：落地 MCP 子 Agent 骨架——预置子 Agent 注册表（§4.1.2 工程开发栏 EDA/结构/编码/仿真分类）、MCP 客户端抽象（stdio JSON-RPC 最小集）、子 Agent 调度器（§11.1 失败处理矩阵：重试 [P-44]/[P-45]、指数退避 [P-46]、超时 [P-38]~[P-41]、启动延迟 [P-57]、同类别降级）、工具白名单与 untrusted_data 域（§10）。

## 计划

1. **新模块 `src/mcp/`**：
   - `types.ts`：`SubAgentCategory` / `SubAgentMeta` / `McpTool` / `McpCallResult` / `DispatchResult`
   - `registry.ts`：预置子 Agent 注册（KiCad/Keil/Cursor/FreeCAD/LTspice，默认占位 available=false，命令可配置）
   - `client.ts`：`McpClient` 接口 + `StdioMcpClient`（spawn 进程，initialize/tools/list/tools/call 行 JSON-RPC，启动超时 [P-57]、调用超时 [P-41]）
   - `dispatcher.ts`：`SubAgentDispatcher`——按类别/工具前缀选 agent → 调用 → 超时中断 → 失败重试（确定性 [P-44]/非确定性 [P-45]，退避 [P-46]）→ 同类别降级 → 取消信号
   - `safety.ts`：工具名白名单（toolPrefix 前缀校验）+ 参数 JSON 可序列化校验；返回一律标 `untrusted: true`（§10 MCP 工具返回进 untrusted_data 域）
2. **params.ts 落 §5 已登记参数**：P-38~P-41/P-44~P-46/P-57（C8 引用生效）。
3. **登记**：需求文档 E222；`docs/code-directory.md`、`docs/directory-structure.md`、handoff。
4. **验收**：doc-lint 0 FAIL 0 WARN + build + 全量单测/集成全绿。

**验收标准**

- 预置子 Agent 注册表可查（按类别/按 id），未接入的默认占位。
- 调度器：成功返回（attempts=1）；工具失败按重试次数重试且退避递增；超时中断标记 timedOut；取消信号生效；同类别降级标记 degraded。
- 白名单：非本 agent 工具名前缀拒绝；非 JSON 可序列化参数拒绝；返回均 untrusted。
- doc-lint 0 FAIL 0 WARN；单测 + 集成全绿。

### 遇到的问题

- `McpClient.callTool` 初版无 timeoutMs 覆盖，调度器无法按操作类型收紧超时 → 接口补可选第三参。
- 降级设计：按 toolName 前缀匹配后同类别备用不在候选，且降级仍用原工具名会撞白名单 → 候选追加同类别可用 agent，降级回退其默认 run 工具。
- 显式指定工具名但无任何 agent 前缀匹配时，从「任意可用兜底」改为诚实失败（不悄悄换工具）。
- C8 要求 params 每个 key 有非测试引用：P-38/39/40 通过调度器 `opKind` 默认超时引用（§11.1.3 语义一致）。
