# 推进计划：图片 OCR 文字提取（E164）

> 日期：2026-08-20 · 分支：v0.2b · 状态：已完成

## 目标

生活助手支持从上传图片（照片/截图/扫描件）提取文字：
- 新脚本 `scripts/office_image_ocr.py`：Pillow 解码（HEIC 走既有解码链）+ RapidOCR/PaddleOCR 识别，
  输出文本并可选落盘 txt；
- `office-daily` 新增 `image_ocr` 模式（识别/提取文字关键词触发），引擎缺失时诚实提示安装命令；
- 测试：引擎禁用诚实提示（确定性）+ 本地 rapidocr 真识别（特性门控）。

## 计划

1. `office_image_ocr.py`：复用 pdf_text.py 的引擎加载与结果抽取；支持 PDF_OCR=0 关闭与 PDF_OCR_ENGINE 选择。
2. `office-daily`：OfficeMode 加 `image_ocr`，modeFrom 加关键词，执行分支写临时图（保留扩展名）→ runPython → 落盘 txt。
3. 测试 2 条：PDF_OCR=0 诚实提示；本地 rapidocr 门控真识别（Pillow 生成含文字图片）。
4. 登记附录 A（E164）、更新 plan/handoff/skills README；跑 build/test/doc-lint。

**验收标准**

- 单测新增 ≥2 条全绿，集成 17/17 不变；doc-lint 0 FAIL 0 WARN；
- 上传含文字图片 → 返回识别文本摘要并落盘 txt；无 OCR 引擎 → 诚实提示安装命令。
