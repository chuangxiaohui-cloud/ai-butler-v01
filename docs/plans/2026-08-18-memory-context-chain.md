# 推进计划：B 套记忆上下文链路（E131）

> 日期：2026-08-18 · 分支：v0.2b · 状态：已完成

## 目标

打通 B 套 EC10/EC24/P08 等场景依赖的“近期记忆 → 路由上下文 → 原文回溯”链路，
让 rewrite 类请求能从上一轮 Q+A 中取原文润色，而不是固定要求用户重发内容。

## 计划

1. L0 记忆按 `userId` 分会话读写，避免多用户共用 `v0.1-cli`。
2. `session_summaries` 摘要改为 `Q: 原文\nA: 回答` 双字段，供后续路由与润色回溯。
3. LLM 意图特征提取注入历史上下文，路由消歧不再只看当前一句。
4. rewrite 分支新增“近期记忆取原文 + 文本 LLM 润色”，无原文时保留原澄清话术。
5. 补单测与回归，更新 E131、计划结果与当天交接。

**验收标准**

- 同一 userId 的正式轮能召回上一轮 seed 的 Q+A。
- `把刚才那段话...重写一遍` 能从近期记忆取原文并输出润色结果。
- 无原文时仍返回“请把要重写的内容发给我”，不硬猜。
- 主项目 build、单测全绿、doc-lint 通过。

## 执行过程

### 改动

- `src/search/pipeline.ts`：按 userId 召回/写入 L0；会话摘要带 Q+A；rewrite 接近期记忆。
- `src/agent/extract.ts` / `intent-feature.ts`：特征提取 prompt 注入历史上下文。
- `src/agent/router-v2.ts`：把上下文透传给 LLM 特征提取。
- 新增 `src/agent/rewrite-with-memory.ts`：从 Q+A 记忆提取原文并润色。
- 更新相关单测、v2.5 附录 A、进度交接。

### 遇到的问题

- CLI 真跑 P08 两轮，正式轮直接从上一句输出润色结果，与单测预期一致；
  B 套其余场景暂未全量重跑，留作下次基准验证。

## 结果

- 验证：`npm run build` 通过；`npm run test:all` 单测 384/384 + 集成 17/17 全绿。

  “经评估，该方案整体可行，唯报价方面略高于预期……”，不再要求重发内容。
- B 套人工评分：28 轮已回填到 `bench/devil-v25/b-multiturn.md`，平均 2.25，
  重跑脚本会保留旧评分与点评。
