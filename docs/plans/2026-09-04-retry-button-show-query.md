## 改动

- `ui/prototype/src/App.tsx`（`MessageItem`）：按钮文案从 `↻ 重试` 改为 `↻ 重试「{原句}」`（超过 16 字截断加 …），
  `title` 放完整原句提示；重试中仍显示 `重试中…`。
