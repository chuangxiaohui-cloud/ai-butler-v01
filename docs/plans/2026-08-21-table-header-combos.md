# 推进计划：组合复杂表头还原（整行标题 + 多级分组 E175）

> 日期：2026-08-21 · 分支：v0.2b · 状态：已完成

## 目标

承接 E174（网格线检测 + 跨行合并）。E174 的空区间启发式只作用于第 0 行，且无法
推断“整行居中标题”的跨度：组合表头图真跑显示——`销售汇总`（跨 4 列）只还原成
跨 2 列，`华东/华北`（第 1 行的两级分组）完全没检出。本期扩展启发式：①空区间
启发式覆盖前 2 行（组间空隙模式护栏，避免缺值数据行误并）；②整行居中标题检测
（单文本、居中、两侧下方有内容 → 合并整行，并撤销槽位法的部分合并）。

## 计划

1. `scripts/office_image_ocr.py` `detect_merges`：
   - 表头行范围从第 0 行扩到前 2 行；行内空区间数 + 1 ≥ 该行填充数才启用
     （组间空隙模式，缺值数据行 `[10,,8,9]` 3 文本 1 空隙不触发）。
   - 整行居中标题：填充数 == 1 且文本中心距行中心 < 15% 行宽、两侧空区间下方
     均有内容 → 合并整行，撤销该行既有部分合并（槽位法结果被替换为整行）。
2. 真跑：组合表头图 → `销售汇总` A1:D1、`华东` A2:B2、`华北` C2:D2 共 3 处。
3. 测试：新增组合表头真跑（xlsx 读回 `model.merges` 3 处 + 答案“已还原 3 处”）；
   回归既有 2×2/宽表头/两级表头/跨行/无网格 5 用例。
4. 文档：附录 A 登记 E175（压缩 E64 腾行）、skills README、handoff、doc-lint。
