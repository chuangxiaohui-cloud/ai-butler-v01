# 推进计划：B 套重跑验证 E133-E135

> 日期：2026-08-19 · 分支：v0.2b · 状态：已完成

## 目标

在 E133/E134/E135 落地后全量重跑 `bench:devil-b`，验证：
P04/P07 的“记住/老规矩”记忆链路、C03 的“刚才说的”回溯边界、
C07 的 Agent 回滚能力，并确认 B 套人工评分不被覆盖。

## 计划

1. 运行 `npm run bench:devil-b`。
2. 对比 EC02/P04/P07/C03/C07 等关键轮的新回答。
3. 确认 `b-multiturn.md` 保留原人工分与点评。
4. 更新交接记录。

**验收标准**

- 脚本正常结束，14 场景全部落盘。
- P04/P07 种子轮不再搜索外部资料噪声，正式轮能召回事实。
- C03 正式轮遇到“刚才说的”时不再把通用经验说成刚才说过。
- C07 无操作记录时返回诚实说明。
- 原人工分保持 28 轮、平均 2.25。
