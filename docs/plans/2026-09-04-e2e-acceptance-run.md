## A 组：日程 / confirm 真阻断链路（E324–E330）

### A1 亲子游句（E325/E326/E327）
- 聊天输入：`帮我安排一下我家里明天的亲子游行程安排`
- 预期：确认文案人称第二人称（“你让我‘帮你安排一下你家里明天的亲子游行程安排’”）；批准后回执
  `✅ 老板，已按你的批准执行。已为你创建日程：亲子游行程（…）`；标题无“一下/我家里”。

### A2 周会提前提醒句（E329/E330）
- 聊天输入：`帮我安排明天下午3点的周会，提前10分钟提醒`
- 预期：出现「⏸ 待你裁决/执行」确认卡（非“本地兜底”）；批准后创建的是**日历事件**（标题「下午3点周会」，
  无“提前…提醒”残留），**不是**一次性提醒；执行回执不再拼 `> ai-butler…` / `M ../../../…` 的 git 噪音。
- 补充：裁决面板（右栏「裁决」）对同一句批准，也应得到同样的日历事件回执（E324 第二刀）。

### A3 否决与重复挂起（E324）
- 输入一句写类请求后选「取消/否决」→ 回「已取消该操作，不会执行」，`data/decision-log.jsonl` 追加一行否决事件；
- 同一会话已有待批准项时再发写类请求 → 提示先处理上一条，不重复挂起。

## B 组：UI 旁路能力（E328/E331/E332/E333）

### B1 目录监听（E328）
- 用记事本在 `M:\202608111\projects\` 下新建/修改/删除一个文件并保存
- 预期：右栏「文件」面板约 2s 内自动刷新（无需手动点刷新）；`~$`、`.tmp` 等临时文件不触发。

### B2 通知角标与分页（E331）
- 在对话触发一条写类挂起 → 右栏非「通知」页时“通知”tab 出现红色未读数字；进「通知」页角标清零；
- 通知超过 20 条时显示「共 N 条 · 第 x/y 页」，可上一页/下一页。

### B3 离线兜底与重试（E332/E333）
- `Ctrl+C` 停掉 gateway → 聊天任意提问 → 出现 `⚠️ 网关未连接…（本地预览，非真实回答）`，无假证据；
- 重开 gateway → 兜底按钮应显示 `↻ 重试「{原句}」`（原句预览），点击后收到真实回复且不重复用户气泡。

## C 组：CLI / 桌面冒烟

- C1 身份问答（免外部网络）：`npm run dev -- "你现在是什么模型"` → stdout 结构化 JSON，answer 含 `AI-Agent` 与模型 label。
- C2 桌面壳：`npm run desktop` 起壳 + `npm run desktop:smoke` 冒烟；无 GUI 环境则登记 skip。
- C3 gateway 读 API：`Invoke-WebRequest http://127.0.0.1:8787/api/decisions` → 200 且 `open` 为数组（可空）。
