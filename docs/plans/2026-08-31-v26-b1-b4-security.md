## 目标

落地 roadmap B1~B4 安全治理：4 项写盘 Skill 补沙箱门禁、video-learner ASR/B站域白名单、market/installer 安装日志补 manifest 快照、browser-session 完整域名白名单。全部为纯代码安全收紧 + 离线单测，无 §5/§6 数值变更。

## 计划

1. **B1**：`src/security/sandbox.ts` 新增 Skill 应用数据目录白名单 `isSkillOutputAllowed`（`data/{office,learned-videos,boms,calendar}/**`，对齐审计 §3.2 建议）+ 门禁助手 `guardSkillOutputPath`（显式注入 outDir 的测试/受信调用方跳过，生产默认路径必须过白名单 + 审计日志）；calendar-skill / schematic-bom / office-daily / video-learner 四处写盘点接入门禁。
2. **B2**：`video-learner` 新增 `VIDEO_LEARN_ALLOWED_HOSTS` env 白名单（默认 bilibili.com / bilivideo.com / bilivideo.cn / hdslb.com），B站响应里的字幕 URL / 媒体 URL（untrusted_data）下载前必须过域白名单。
3. **B3**：`market/types.ts` `MarketInstallRecord` 增 `manifestSnapshot` 字段，`installer.ts` 落盘时快照 manifest，补测试断言。
4. **B4**：`browser-session` fetchPage/downloadFile 增可选 `allowedHosts` 参数，命中域名白名单校验（`isDomainMatch`），未提供时保持现有 SSRF-only 行为；video-learner 透传其域白名单。

- `npm run build` 绿；相关单测全绿（sandbox / calendar-skill / schematic-bom / office-daily / video-learner / market-installer / browser-session）。

- 非白名单 host 的字幕/媒体 URL 不下载；安装记录含 manifest 快照；session 带 allowedHosts 时非白名单域名拒绝。
