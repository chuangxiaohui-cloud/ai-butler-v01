# 推进计划：跨页大表拼接鲁棒性——表头匹配加结构证据与真实感样本验证（E186）

> 日期：2026-08-22 · 分支：v0.2b · 状态：已完成

## 目标

承接 E185（多页 PDF 跨页拼接）。E185 的表头去重只靠 OCR 文本精确匹配（70% 阈值），
真实扫描件下页表头 OCR 可能带噪声（数字 0→O、字残半、透字干扰）导致文本匹配失败、
重复表头无法去重。本期：
1. 复核启发式常量（表头匹配阈值 70%、PDF 渲染 DPI=200）；
2. 给表头匹配加 **span 级结构证据**（非空格列位置模式 + 归一化文本），OCR 噪声下仍能
   识别重复表头；
3. 用真实感合成样本（第 2 页带旋转 + 透字 + 表头文本噪声）验证拼接仍去重、正文仍追加。

## 计划

1. `scripts/office_image_ocr.py`：
   - `_row_similar` 升级：① 文本先归一化（去空白）再比较；② 70% 文本匹配通过判同；否则
     若**非空格列位置模式相同**（该行哪些列有内容，来自 TSR span 的行列归属）也判同——
     OCR 文本噪声下结构不变，仍能识别重复表头。
   - `_common_header_rows` 增加守卫：公共前缀行数不超过首页表头高度的一半时视为“无法
     确认表头重复”，避免把正文首行误当表头（h 判据与既有文本匹配并列）。
   - DPI 常量复核：快速实验 150/200/250 三档，确认 200 合理；结论记入本计划。
2. 测试：`index.test.ts` 新增 1 条真跑——合成 2 页 PDF：第 1 页干净表头+2 行正文；第 2 页
   表头文本带噪声（`2024`→`2O24`，结构不变）+ 页面旋转 1.2° + 头部透字残影，正文 2 行；
   断言 xlsx 仍为 6 行 × 5 列、merges 仅首页表头、答案含“2 页拼接”与“已还原 3 处”。
3. 文档：附录 A 登记 E186、skills README 微调、handoff 更新、doc-lint 全绿。

**验收标准**

- 带噪声/旋转/透字的第 2 页 → 表头仍去重（6 行 × 5 列），零 warning，答案含“2 页拼接”。
- 既有 E185 2 页干净用例与全部单图用例 merges 输出不变，零回归。
- 单行正文（如 `手机 | 100 | 200 | 300 | 400`）与表头行结构模式不同，不会被误判为表头。
- `npm run build` + `npm run test:all` + `doc-lint`（0 FAIL 0 WARN）全绿。

## 执行过程

### 改动

- `scripts/office_image_ocr.py`：
  1. `_row_similar` 升级：文本匹配（≥70%）之外新增 **span 级结构证据**——非空格列位置模式相同
     且至少一个非空格格文本一致（OCR 噪声/透字粘连导致表头文本变化但列结构不变的重复表头仍可
     识别；文本锚点守卫防稀疏正文行误判）。文本先归一化去空白再比较。
  2. `detect_table_lines` 新增 `_merge_near_edges`：相距 ≤5px 的网格线候选边合并为一条（200dpi
     渲染页细线被透字抑制打成碎片时同一条线裂成两段，产生幻影空行/列；真实表列宽 ≥15px 不受影响）。
  3. 阶段 C 空区间合并补守卫：`start==0` 且 `end==cols-1`（整行空格）时跳过，防 `anchor_c` 越界
     崩溃（矮表/分隔空行不再触发 IndexError）。
- `src/skills/office-daily/index.ts`：`TableMergeWarning` 类型新增 `page_header_mismatch`/
  `page_col_mismatch`；`tableWarningsNote` 分页对齐告警单独成句（“检测到 N 处分页对齐问题…手动调整”），
  合并类告警文案不变。
- 测试：`index.test.ts` 新增 1 条真跑 2 变体（E186）：A）第 2 页表头文本噪声（2024→2O24）+ 旋转
  1.2° + 头部透字残影 → 结构证据去重表头，xlsx 6 行 × 5 列、merges 仅首页表头、零 warning、答案
  含“2 页拼接”；B）第 2 页无表头仅正文 → 诚实降级（整页追加 + `page_header_mismatch` 告警，不崩溃
  不丢数据）。

### 遇到的问题

- **`detect_merges` 阶段 C 越界崩溃**：真实感验证时发现 2 行矮表（PDF 渲染 834px 高）在阶段 C
  报 `list index out of range`——透字抑制把水平网格线打成碎片 → 幻影空行 → 整行空格空区间走到
  `start==0` 分支、`anchor_c=end+1=cols` 越界。两层修复：`_merge_near_edges` 消除碎片（根因），
  阶段 C 整行空格守卫（防御，防其它路径再触发）。
- **结构证据的防误判设计**：纯列模式匹配可能把稀疏正文行（“小计|空|空|空|空”）误判为表头，
  因此结构证据要求“模式相同 **且** ≥1 个非空格格文本一致”；无表头续接页实测不被去重、诚实告警。
- **DPI 复核**：150/200/250/300 四档渲染全部 6 行 × 5 列、表头去重正确，200 为分辨率与耗时折中，
  维持 `TABLE_PDF_DPI=200`。
