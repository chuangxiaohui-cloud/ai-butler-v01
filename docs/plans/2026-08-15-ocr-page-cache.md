# 推进计划：扫描件 OCR 单页缓存

> 日期：2026-08-15 · 分支：v0.2b · 状态：已完成

## 目标

同一扫描页重复进入二次取证时，不再重复跑 RapidOCR：按页图哈希落盘缓存识别文本，第二次直接读缓存，显著降低耗时。

## 计划

1. `scripts/pdf_text.py`：OCR 前渲染页图并计算 SHA-256，命中 `data/ocr-cache/` 缓存则直接返回文本；未命中则 OCR 后写缓存。
2. 用单页扫描 PDF 跑两次：第一次生成缓存，第二次命中缓存。
3. 跑 `npm run test:all` 与 doc-lint。
4. 登记 v2.5 附录 A（E89）、更新文档，提交推送。

**验收标准**

- 第一次 OCR 后 `data/ocr-cache/` 生成缓存文件。
- 第二次跑同一页快速返回文本（不再推理）。

## 执行过程

### 改动

- `scripts/pdf_text.py`：OCR 前渲染页图并计算 SHA-256，命中 `data/ocr-cache/` 缓存直接返回文本；未命中则 OCR 后写缓存，缓存文件名带引擎版本前缀 `v1-`。

### 遇到的问题

- 无阻塞问题。

## 结果

- 验证：单页扫描 PDF 第一次 OCR 约 17.9s 并生成 1 个缓存文件，第二次约 2.0s 命中缓存，返回相同 1,299 字符。
- 测试：单测 255/255 + 集成 17/17 全绿；doc-lint 0 FAIL/0 WARN。
- 提交：`e52423a` · 推送：Gitee / GitHub
- 遗留事项：PaddleOCR 精度对比未做；缓存目录可后续加清理策略。
