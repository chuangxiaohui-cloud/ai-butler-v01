# 推进计划：表格网格线检测 + 跨行合并还原（E174）

> 日期：2026-08-21 · 分支：v0.2b · 状态：已完成（验证全绿）

## 目标

承接 E173。E173 用文本中心聚类重建网格，跨行合并文本（位于两行之间，如“部门”跨
row0/row1）会被拆成独立行，导致行列结构错误（4 行）与误判（“一月/二月”被误合并）。
本期引入真实网格线检测（PIL/numpy），用网格边界确定行列结构，把合并还原从几何启发式
提升为结构级判定；无网格（无边框）表格回退文本聚类路径，行为与 E173 一致。

## 计划

1. `scripts/office_image_ocr.py`：
   - 新增 `detect_table_lines(arr)`：灰度图按行/列统计暗像素比例 + 最大连续暗 run 双条件
     检线（避免密集文字行误判），相邻线合并，返回 `([x_edges...], [y_edges...])` 或 None。
   - 新增 `reconstruct_grid(items, x_edges, y_edges)`：按网格单元归属文本（中心落格），
     行列结构由网格线直接确定；bbox 跨格的文本仍落到首个单元格，由槽位法补判合并。
   - `detect_merges` 支持外部传入网格槽位边界（替代文本中心中点槽位）。
2. `main()` `--table`：先检网格 → 网格路径；无网格回退 E173 文本聚类路径。
3. 真跑：跨行合并图（A1:A2）→ merges rowSpan=2、grid 3×2；回归既有 2×2/宽表头/两级表头。
4. 测试：新增跨行合并真跑（xlsx 读回 `model.merges` 含 `A1:A2`、答案含“已还原 1 处…
   跨行 1 处”）；新增无网格回退断言。
5. 文档：附录 A 登记 E174（压缩 E63 腾行）、skills README、handoff、doc-lint。

**验收标准（本次对齐）**

- 跨行合并图 → xlsx `A1:A2` 合并，grid 正确 3 行 × 2 列，答案含“已还原 1 处合并单元格
  （跨列 0 处、跨行 1 处）”。
- 既有 3 用例（2×2 网格、宽表头、两级表头）merges/warnings 输出与 E173 完全一致。
- 无网格（无边框）表格回退文本聚类路径，不报错、不产生伪合并。
- `npm run build` + `npm run test:all` + `doc-lint`（0 FAIL 0 WARN）全绿。
