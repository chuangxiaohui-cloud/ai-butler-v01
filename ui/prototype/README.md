# 一人公司 AI-Agent · v1.0 三栏 UI 原型

> 独立 Vite + React 原型，不污染主仓库构建。

## 运行

```bash
npm install
npm run dev
```

默认地址：`http://127.0.0.1:5173/`

## 覆盖的规格

- §4.1.1 三栏布局（工程开发 / 知识咨询 / 生活助手）与 Ask / Craft / Plan 正交。
- §4.1.2 工程开发栏：角色面板、子 Agent 状态、对话区、产物区、内置终端与内置浏览器。
- §9.1-9.2 证据链：`[hard]` / `[soft]` 证据标签，可点击的证据卡片。
- §9.3 轻量反馈：回复下方的 👍 / 👎 / 修改建议。

视觉风格：深色 AI 工作台（近黑面板 + 蓝色强调），顶栏三栏导航，工程栏左侧 MCP 子 Agent、中间对话、右侧产物与变更记录、底部终端和状态栏。

## 验证

- `npm run build` 通过。
- Playwright 检查：三栏与移动视口均无横向溢出，控制台无错误。
