# Bench B-20260828-02：合成输入预算瘦身（正文注入 3000→1500，E276）

> 日期：2026-08-28 ・ 对应 E276

## 目的

E275 交付后用户实测「中国AI大模型公司市值较高的是哪几家？」仍答非所问：桌面实测 55~90s/次、token 消耗高，超时兜底输出「搜索到了 N 条…已抓取正文：T（U）；T（U）」URL 墙。本基准记录正文注入上限 [P-128] 3000→1500 字符 + 超时兜底重写后的真实复测数据，验证与 [P-06]/[P-116] 12s 合成预算匹配。

## 方法

- 真实管道，桌面默认档 medium = deepseek-v4-flash（[P-116] 12s 预算）；heavy = deepseek-v4-pro（[P-130] 30s）
- 同一 query「中国AI大模型公司市值较高的是哪几家？」多次复测：记录 prompt 字符规模、是否预算内直接作答、超时降级输出形态与 gate
- 对照 `DIAGNOSE_NUMERIC=1` 候选池 dump：召回/融合正常（证据已含 guba 讯飞1022亿/三六零555亿/昆仑万维408亿），问题定位在合成输入规模

## 结果

### prompt 规模（单篇注入 [P-128] × 3 篇正文）

| [P-128] 配置 | prompt 字符 | 估算 tokens | 备注 |
|------|------|------|------|
| 3000（修复前） | ~7320 | 8~10k | medium 超时 |
| 2000（中间态） | 6627 | ~7k | 仍偏高 |
| 1500（修复后） | 4921~5020 | 4.4~5k | 预算内收口 |

### medium（deepseek-v4-flash）5 次复测

- 2 次 LLM 直接作答：elapsed 10.4~11.5s，答案含 智谱破1万亿港元 / 寒武纪6300亿 / 摩尔线程3100亿 / 沐曦2500亿，gate=none
- 3 次 deepseek API 延迟撞 [P-116] 12s → 新 fallback：干净、带数字、gate=synthesis_timeout 正确（不再输出「搜索到了 N 条」URL 墙）

### heavy（deepseek-v4-pro）CLI 复测

- 仍撞 [P-130] 30s（E274 已知行为），fallback 干净（来源标题/域名 + 正文片段 + 独立 URL）

### flash 延迟探针

- 小 prompt 1.2s；同规模 prompt 9.2s → 主因 deepseek API 延迟波动；1500/页已把超时收敛到偶发

## 结论

- [P-128] 3000→1500 后 prompt 规模降约 1/3，medium 合成在 12s 预算内稳定收口；数值/列举类页面关键数据在正文头部，截断不丢数字
- 超时降级不再输出 URL 墙，改为「回答生成超时…」+ 来源标题（或域名）+ 正文头部 120 字片段 + 独立 URL，按 URL 去重
- 桌面实测 55~90s/次 → 预算内收口；残余为 deepseek API 延迟波动偶发超时（显式兜底已可读可用）
