# 表格 OCR：方向 1（PaddleOCR）实测归档 + E201 词典扩展

> 日期：2026-08-23 · 样本：OCRtest.png × 《人脸识别仪（闸机式）BOM-20171106.xls》50 行基准 · bench:B-20260823-01

## 1. 方向 1（换 PP-OCRv6）实测结论：不达标，归档

- 实验：`data/exp-paddle.py`（paddleocr 3.7.0 / paddlex 3.7.2，PP-OCRv6_medium det+rec；基准真值预提取 `data/exp-paddle-gt.json`，规避环境 xlrd 残缺）。
- 排障链：① xlrd 残缺/命名空间包 → 真值 JSON 兜底；② oneDNN 指令不兼容（`ConvertPirAttribute2RuntimeAttribute not support`）→ `PADDLE_PDX_ENABLE_MKLDNN_BYDEFAULT=False`（同 E97）；③ `rec_boxes` 为 `[l,t,r,b]` 而非 4 点 → 通用解析。
- 原图（关文档方向/透视/文本行预处理，保证坐标与评估网格对齐）逐格对照：

| 目标残差 | RapidOCR+E200/E201 | Paddle PP-OCRv6 原图 |
|----------|--------------------|----------------------|
| 需胶枪→糖胶枪 | 已修（落胶枪变体） | 同样读出 `白色（糖胶枪）` ✗ |
| FR405 `2.54-9P扁排线…` 乱码 | 残差 | `2.54-F房排线（一头26P牛角插失…` ✗ |
| FR407 单位 `套` 漏检 | 残差 | 该格无检出 ✗ |

- Paddle 新引入错误：`LBD补光灯`、`宣鼎SSD`、`GO70VW01`、`LVD8线`、`外亮模具`（RapidOCR+E201 均正确）。
- 耗时：单图 `predict` 约 240s（RapidOCR 1-3s，慢约 100 倍）。
- 结论：PP-OCRv6 未解决任何一处目标残差且慢 100 倍 → 方向 1 归档，默认引擎维持 RapidOCR；`PDF_OCR_ENGINE=paddle` 保留为可选慢速通道。
