# 表格 OCR：网格补位（FR407 单位「套」整格漏检）+ 残差收口

> 日期：2026-08-23 · 样本：OCRtest.png × 《人脸识别仪（闸机式）BOM-20171106.xls》50 行基准 · bench:B-20260823-02

## 1. 网格补位（E205）

- 现象：FR407 行单位列「套」在 cleaned/灰度/2x 全图三通道均未检出（整格漏检），词典无法补缺失文本。
- 根因：该格文本过小/对比低，全图检测阶段被整体跳过；单格裁剪后原尺寸 OCR 即可检出。
- 实现（`scripts/office_image_ocr.py`）：`_grid_fill_empty_cells`——按网格线（x_edges/y_edges）裁剪
  「编号锚定数据行」内空的非代码列单元，原尺寸 OCR 优先、2x 预处理兜底，score≥0.95 且 ≤4 字符才补入。
  护栏：仅补「短值列」（列内已检出文本全部 ≤4 字符，如数量/单位）；排除合并覆盖单元；
  不补代码列；与 E200 补框同语义（编号锚定行才补），避免把透字/水印残影当数据。
- 新 warning 类型：`grid_filled`（透出补位数量，供 UI 提示）。
- 实测：FR407 单位「套」score 0.979 补入；FR407-01~-20 单位真值本就为空，未误补。
- 开销：OCRtest.png 全表 +15s（裁剪重 OCR 仅限短值列空单元）。

## 3. 残差收口

- 方向 1（PaddleOCR）实测归档（B-20260823-01）；方向 3（超分）维持暂缓。
- E201 词典扩展后：登加型→叠加型（型号 48/48）、FR405 乱码→规范值。
- E205 网格补位后：FR407 单位「套」补入（单位 47/48）。
- 已知限制（诚实登记）：① FR133 合并行在 OCR 输出中为两物理行（`叠加型 分开型`/`1 1`/`条 条`），
  与真值合并格（`叠加型/分开型`/`1/1`/`条/条`）为结构口径差异，各单元文本本身正确；
  ② 编号 `FR116（2)` 右括号半角 vs 真值全角，属字形细节；③ 网格补位仅覆盖短值列，
  长文本列（名称/型号/备注）整格漏检仍无法补。
