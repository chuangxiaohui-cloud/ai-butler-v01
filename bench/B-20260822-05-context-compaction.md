# Bench B-20260822-05：§8.3 会话上下文压缩真实冒烟（E193）

> 日期：2026-08-22 · 对应 E193（§8.3 工作记忆与上下文压缩落地）

## 目的

验证同一会话内超出逐字窗口（[P-29]=5 轮）或 [P-109]=6000 token 预算的早期轮次，
由真实轻模型压缩为「实体 + 决策 + 未决事项」结构化摘要，并确认全链路
（append → compactIfNeeded → 窗口保留 + 滚动摘要）可用。

## 实测记录

| 项 | 值 |
|----|-----|
| 轻模型 | `createLightClient()`（Provider fallback 链，真实 key） |
| 1) 压缩 2 轮合成对话（4 轮次） | 1245ms，输出三类标记齐全 |
| 2) 全链路 append 8 轮 → compactIfNeeded | 1579ms，窗口保留 5/5 轮，滚动摘要生成 |

### 1) 轻模型压缩输出（转写）

输入为 2 轮合成对话（STM32F103C8T6 项目选型 + I2C 上拉电阻），轻模型输出：

```
实体：STM32F103C8T6；主频72MHz；KiCad 6；I2C上拉电阻4.7k/10k；400kHz
决策：PCB工具选KiCad（开源免费）；I2C上拉电阻选4.7k（400kHz下更稳）
未决：总线电容大时需重新评估上拉电阻值
```

- 标记命中：实体 / 决策 / 未决 三类齐全；关键实体（STM32 / KiCad / 4.7k）保留。
- 摘要长度远小于原始轮次转写，达成「保留关键信息，不占大量 token」。

### 2) 全链路触发（8 轮 → 压缩）

- append 8 轮后 `compactIfNeeded` 触发：窗口外 3 轮移入压缩，窗口保留 5/5 轮（[P-29]）。
- 滚动摘要生成（示例：`实体：内容1；内容2；内容3。决策：无明确选择或理由。未决：内容1、内容3待确认…`）。

## 结论

- 真实轻模型压缩链路可用：超窗轮次被压缩为结构化摘要，逐字窗口内轮次完整保留；
  [P-109] token 预算为硬约束、[P-29] 轮数为窗口下限，双触发与 §8.3 一致。
- 压缩失败静默、不阻塞主回答（8s 超时降级），远期会话仍走 L1-L3 蒸馏，记忆分层不变。
